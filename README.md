A faster drop-in for makefun-site 1.0.0 — builds the same static sites byte-identically, at a fraction of the CPU time. Inline Markdown is scanned in bulk with native indexOf jumps, slugify takes an ASCII fast path with a per-run memo, word counting is allocation-free, and templates are compiled once per run.

## Run it

```sh
node main.ts
```
